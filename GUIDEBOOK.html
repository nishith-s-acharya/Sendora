📖 ReachInbox Email Job Scheduler — Run Guidebook

A complete handbook for setting up, running, testing, and monitoring the system.

QUICK ACCESS

Frontend: http://localhost:5173
Backend API: http://localhost:3001

1. Quick Start (3 Terminals)

# Terminal 1: Backend API
cd backend
npm run dev

# Terminal 2: BullMQ Email Worker
cd backend
npm run worker

# Terminal 3: Frontend Dashboard
cd frontend
npm run dev

2. Infrastructure (Postgres & Redis)

# Start with Docker:
docker compose up -d

# OR Start with Homebrew on macOS:
brew services start postgresql@16
brew services start redis

3. TablePlus Connection Details

Service Connection URL / Details
PostgreSQL postgres://reachinbox:reachinbox_pass@localhost:5432/reachinbox_db
Redis redis://localhost:6379

4. Core User Workflow

  1. Open http://localhost:5173 and click "Continue with Google".
  2. Click "+ Compose Email" in the sidebar.
  3. Enter Subject, Body, upload a CSV/TXT with recipient emails, set Start Time, Delay, and Hourly Limit.
  4. Click "Schedule Email".
  5. Watch real-time status updates on the dashboard and click the rendered email preview URLs in the worker console.
